IMPORTANT: GitHub Actions only runs workflows from a folder named .github/workflows.

If your file picker hides dot-folders, this visible GITHUB folder is a backup copy.
Before uploading the project to GitHub, create this exact path in the repository:
.github/workflows/build-apk.yml
and upload/copy the build-apk.yml file from this folder there.

The ZIP also contains the real .github/workflows/build-apk.yml folder.
